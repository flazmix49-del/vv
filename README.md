# blagovisual (Fabric 1.21.4)

Клиентский визуал-мод.

## Возможности
- **Кастомный прицел**: 5 стилей (крест, точка, круг, ромб, крест+кольцо), 5 цветов включая анимированную радугу,
  динамический разлёт при беге/прыжке/ударе, краснеет при наведении на моба или игрока.
- **TargetHUD**: плавная полоска здоровья с градиентом и затуханием.
- **Ватермарка** с градиентом, FPS и пингом, **инфо-панель** (координаты, скорость).
- **AutoSwap** (клавиша `G`): мгновенно меняет предмет в левой руке на выбранный
  (тотем / золотое яблоко / щит / зач. яблоко / жемчуг) из хотбара или инвентаря.
  Красивое уведомление над хотбаром.

## Клавиши (меняются в Управление → blagovisual)
- `G` - AutoSwap
- `Right Shift` - меню настроек
- прицел вкл/выкл - не назначена по умолчанию

## Сборка
Нужны JDK 21 и Gradle 8.x:

    gradle build

Готовый мод: `build/libs/blagovisual-1.0.0.jar`. Кладите в `mods/` вместе с Fabric Loader 0.16+ и Fabric API для 1.21.4.
Либо откройте папку в IntelliJ IDEA - проект импортируется сам.
